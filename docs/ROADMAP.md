# Roadmap

## MVP (v0.1) — Current
- [x] Electron shell with floating overlay
- [x] Screen capture with OCR (Tesseract.js)
- [x] Chat interface with streaming AI responses
- [x] OpenAI + Ollama provider support
- [x] Context Transparency Panel
- [x] Privacy Dashboard (pause, delete, inspect)
- [x] Session management
- [x] SQLite local storage
- [x] Settings page
- [x] Global hotkey (Ctrl+Shift+Space)
- [x] Status indicator (Capturing / Paused / Processing)

## v0.2 — Enhanced Capture
- [ ] App allowlist / blocklist for capture
- [ ] Active window detection and auto-context
- [ ] Multi-monitor support
- [ ] Region selection capture (crop before OCR)
- [ ] Screenshot redaction tools (blur sensitive areas)

## v0.3 — Smarter AI
- [ ] Multi-modal AI (send screenshots directly to GPT-4V / LLaVA)
- [ ] Custom system prompts per workflow
- [ ] Prompt templates library
- [ ] RAG over local documents
- [ ] Code-aware context (detect IDE, pull file content)

## v0.4 — Workflows & Automation
- [ ] Custom action buttons (user-defined prompts)
- [ ] Workflow chains (capture → analyze → draft → copy)
- [ ] Clipboard integration (auto-copy responses)
- [ ] Keyboard shortcuts for each action
- [ ] Export sessions to Markdown

## v0.5 — Platform & Polish
- [ ] Light theme
- [ ] Resizable overlay with saved position
- [ ] Auto-start on boot
- [ ] System notifications
- [ ] Onboarding / first-run wizard
- [ ] Plugin system for community extensions

## v1.0 — Production Ready
- [ ] End-to-end encryption for stored data
- [ ] Signed builds (macOS, Windows, Linux)
- [ ] Auto-update mechanism
- [ ] Performance optimization (lazy OCR, image compression)
- [ ] Accessibility (screen reader, keyboard navigation)
- [ ] Internationalization (i18n)
